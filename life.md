# Game of Life Web Page

A fully functional implementation of Conway's Game of Life created in `life.html`.

## Features

- **Interactive grid** - Click on cells to toggle them alive/dead
- **Start/Stop button** - Run the simulation continuously
- **Step button** - Advance one generation at a time
- **Clear button** - Reset the grid
- **Random button** - Generate a random pattern
- **Speed control** - Adjust simulation speed (1-20 updates/second)
- **Generation counter** - Track the current generation

## Game Rules Implemented

- Live cells with 2-3 neighbors survive
- Dead cells with exactly 3 neighbors become alive
- All other cells die or stay dead

## Design

- Clean, modern UI with gradient background
- Responsive controls
- 50x70 cell grid
- Purple color scheme

## Usage

Open `life.html` in any web browser to start playing with the simulation!
